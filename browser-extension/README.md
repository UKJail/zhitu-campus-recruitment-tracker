# 职途填表助手（本地优先版）

这是一个本地安装的 Chrome Manifest V3 插件。第一阶段只负责保存候选人资料、识别当前网申页字段并在用户点击后填写；不会连接职途 Tracker、Supabase、DeepSeek 或其他服务器。

## 已实现

- 加密本地资料库：PBKDF2-SHA256 派生密钥，AES-GCM 加密；解锁密码不写入持久化存储。首次成功解锁后，插件会在这台浏览器的专属 IndexedDB 中保存不可导出的设备密钥，实现后续自动解锁。
- `AutofillProfileV1` 稳定数据格式：基本信息、联系方式、教育、实习/工作/校园/研究、项目、竞赛、证书、技能、语言、链接、求职偏好、答案库和简历文件。
- 多模板：新建、复制、删除和简体中文/繁体中文/英文切换。
- 本地 PDF/DOCX 文字提取。自动提取只接受明确的姓名、邮箱、手机号和教育线索；其余内容保持空白，必须在资料页核对确认。
- 当前页扫描与一键填写：普通 HTML、React/Vue 受控输入、原生与 Ant Design/Element UI 风格下拉、日期、单选、内容编辑框及动态页面重新扫描。
- 为支持北森、Moka、本地测试页及其他普通网申表单，插件会在首次扫描某个招聘域名时请求该网站的访问权限；同一域名允许一次后不再询问。浏览器系统页仍不可访问，且插件只在用户主动点击扫描或填写时执行，不会上传资料。
- 默认不覆盖网页已有内容，不新增经历区块、不翻页、不提交。
- 资料库中已有明确对应内容的字段会随“一键填写”一起执行；需要复核的内容也会填写并以黄色边框提示，不再要求逐项点击确认。不确定、无资料或安全边界内禁止自动处理的字段会跳过并说明原因。
- 教育资料可分别保存“学历”“学位”“学历类型”和“是否海外院校毕业”，避免真实网申把本科/学士混填，并自动映射招聘网站中的“是/否”选项。
- 多段教育经历会按学历层级自动排序后匹配：博士、硕士、本科、专科；因此最高学历填写第一段，本科填写下一段，不受资料录入顺序影响。
- 搜索型学校下拉框会先输入学校名称、等待联想结果，再选择对应学校；普通下拉框找不到对应选项时会关闭菜单并保持空白，不会让多个菜单叠在页面上。
- 日期组件会尝试 ISO、斜杠和中文年月格式，并触发日期控件所需的确认事件；资料只有年月而网页强制要求完整日时不会编造日期。
- 按网站域名保存自定义字段映射。
- 调试标记模式：扫描后在网页控件旁显示与侧边栏一致的编号，绿色代表可靠、黄色代表填后复核、灰色代表网页已有内容、红色代表无法安全处理；点击网页编号会定位侧边栏记录。
- 一键导出脱敏诊断 JSON，只包含页面域名/路径、字段标签、组件类型、匹配状态和失败原因，不包含 URL 查询参数、网页现有值或资料库填写值。
- 加密备份导出/导入，包含结构化资料、设置及加密后的原简历文件。

## 安装到 Chrome

1. 在项目根目录执行：

   ```powershell
pnpm --dir browser-extension build
   ```

2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本项目的 `browser-extension\.output\chrome-mv3` 文件夹。
6. 打开一个网申页面，点击工具栏中的“职途填表助手”，插件会在浏览器侧边栏打开。

首次使用先创建至少 10 个字符的本地密码。密码无法找回；首次成功解锁后不再重复询问。点击“锁定并忘记”、导入其他备份、清除浏览器扩展数据或卸载插件后，需要再次输入密码。建议在资料录入完成后立即导出加密备份。

## 推荐使用顺序

1. 在“资料”页手工录入，或在“本地数据”页导入 PDF/DOCX。
2. 检查解析结果，修正字段，并点击“我已逐项核对当前资料”。
3. 保存资料，按投递方向建立中文、繁体中文或英文模板。
4. 在网申页面点击“扫描当前页”。
   - 第一次扫描某个网站时，在 Chrome 权限弹窗中选择允许；这是插件读取该页表单结构所必需的，允许记录只保存在 Chrome 本机。
5. 先查看“可靠匹配 / 填后复核 / 保持不动”的清单，再点击一键填写；黄色项目无需逐项确认，但提交前仍应检查。
6. 逐项检查黄色字段；进入下一步后重新扫描。
7. 最终提交始终由用户本人完成。

需要反馈兼容问题时，扫描后点击“在网页显示编号”。可以直接告诉开发者“红色 03、07 需要修改”，或点击“导出脱敏诊断”并提供生成的 JSON；发送前仍建议自行快速检查文件内容。

## 安全边界

插件不会自动填写身份证/护照、银行信息、账号密码、家庭成员、健康信息、验证码、签名或协议勾选，也不会绕过验证码与访问控制。性别、出生日期、政治面貌、GPA、排名、国籍、期望薪资、到岗日期及工作许可等会突出提示复核。

插件不自动操作网页中的文件上传框。请在招聘网站中手动选择要提交的简历，避免插件在文件版本不明确时替你上传错误文件。

## 脱敏验收页

这些地址是本机测试页面，不是永久在线网页。只有测试服务器正在运行时才能打开；关闭运行命令的窗口后，地址也会停止访问。

最简单的方法是双击插件目录中的 `启动模拟网页.cmd`，它会启动服务并打开普通测试页。

也可以在项目根目录手动运行：

```powershell
pnpm --dir browser-extension fixtures
```

看到“脱敏验收页”三个地址后，请保持这个命令窗口打开，然后再访问：

然后分别打开：

- `http://127.0.0.1:4173/`：普通 HTML 表单
- `http://127.0.0.1:4173/beisen-like.html`：北森风格 React / Ant Design 模拟页
- `http://127.0.0.1:4173/moka-like.html`：Moka 风格 Vue / Element UI 模拟页

如果浏览器显示“无法访问此网站”，通常表示测试服务器没有运行；重新双击 `启动模拟网页.cmd` 即可。

测试页不会发送数据，且提交按钮已被拦截。建议至少检查：已有内容不覆盖、重复点击不重复新增、黄色复核、敏感字段跳过、下拉框、级联城市、异步字段加载后重新扫描。

## 开发验证

```powershell
pnpm --dir browser-extension typecheck
pnpm --dir browser-extension test
pnpm --dir browser-extension build
```

真实北森与 Moka 网站的组件会因公司配置而变化。模拟页和自动测试通过不等于已完成真实站点验收；正式使用前仍需按计划用脱敏资料各测试至少五个真实页面，并记录失败字段和组件类型。

## 暂不包含

- Tracker / Supabase 同步
- 云端 AI 字段匹配和跨设备同步
- 自动提交、自动翻页、自动新增经历、验证码处理
- Workday、Greenhouse、Lever 专项适配
- Chrome 商店或 Edge 商店发布

未来连接 Tracker 时，以 `src/types/profile.ts` 中的 `AutofillProfileV1` 为数据合同；第一阶段不包含任何同步代码。
